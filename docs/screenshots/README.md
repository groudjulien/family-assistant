# Screenshots of the README

The [README](../../README.md) shows one screenshot next to each module. They
live here, under the exact file names below — drop a new PNG over an old one and
the README picks it up, no edit needed.

## Capture settings

- **Mobile, 375 × 812** (the app is designed mobile-first; a desktop screenshot
  is unreadable at 45 % of a README column).
- **Dark theme** — the app's default.
- One screen per shot, scrolled to the top, with the page's own title bar
  visible.

## Before you commit one

These are **your household's data**. Names, addresses, balances, guests and
messages all end up in a public repository. Blur, or seed a demo household
first.
